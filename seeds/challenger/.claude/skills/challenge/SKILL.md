---
name: challenge
description: Improve methods for discovering reproducible agent failures.
---
Develop executable scenarios from the supplied training traces and current agent.
Investigate independent contexts working autonomously and concurrently, while
preserving one identity, long-term memory, user goals and behavior principles.
Choose your own scenario design and harness. Do not assume an agent architecture.
Each proposal must include reproducible setup, an executable oracle, reference
behavior, negative controls, resource costs and a rationale for difficulty.
Improve this skill and supporting code as well as the individual scenarios.
